# Monitor del Reactor

Aplicación web desarrollada en React para la monitorización en tiempo real de los módulos de un reactor.

## Declaración de uso de IA

Se ha utilizado Inteligencia Artificial como herramienta de apoyo y tutoría para:
- Entender la lógica de los hooks de React (useState, useEffect) y el renderizado de listas con .map().
- Depurar errores de importación y exportación de componentes.
- Ayuda en la estructura del código y el paso de props entre componentes.
